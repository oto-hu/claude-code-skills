# claude-code-skills

個人事業の日常業務を回している **Claude Code のスキル15本**。実際に毎日動かしているものを、識別子だけ置換して公開しています。

書籍『Claude Codeで自分の業務OSをつくる』（Standby Tech）の付録リポジトリです。各スキルの設計意図・失敗した経緯・なぜその一行が書いてあるのかは書籍のほうに書いてあります。

## 中身

| スキル | 何をするか | 起動のしかた |
|---|---|---|
| `morning` | メール・予定・作業ログを1枚のレポートに | 「おはよう」 |
| `todo` | Notion のタスクを今日の空き時間に割り当てる | 「TODO」 |
| `intake` | 新しい案件を受けるか判定する | 「この案件受けるべき？」 |
| `done` | 完了した作業を日誌に追記する | `/done 内容` |
| `learn` | 学びをノート化して索引に足す | 「学んだ」 |
| `growth-loop` | サイトの数字を見て改善案を出し、反映する | 「CTR」「効果測定して」 |
| `kicho` | 青色申告の複式帳簿に仕訳を入れる | 「記帳して」 |
| `community-finance` | コミュニティの月次収支を登録する | 収支データを渡す |
| `case-manager` | 商談メモから議事録・タスク・次回予定を作る | 商談メモを渡す |
| `seminar-copy` | セミナー告知の文面を生成する | 「告知文作って」 |
| `competitive-research` | 競合調査レポートを生成する | 「競合リサーチ」 |
| `secure-implementation` | 実装前のセキュリティ確認 | 実装タスク全般で自動 |
| `py-worktree` | 複数ファイルの一括改修を隔離して行う | 「一括置換」 |
| `video-edit` | 動画の無音部分をカットする | 動画パスを渡す |
| `議事録整理` | 走り書きを議事録に整える | 「議事録にして」 |

## 使い方

そのままでは動きません。パスも ID も置換してあるからです。

```bash
git clone https://github.com/oto-hu/claude-code-skills.git
cp -r claude-code-skills/skills/morning ~/.claude/skills/
```

コピーしたら `SKILL.md` を開いて、下の表の「掲載時」の値を自分の環境の値に置き換えてください。**置換されている箇所が、あなたが埋める場所です。**

| 掲載時の値 | 置き換えるもの |
|---|---|
| `you@example.com` | 自分のメールアドレス / カレンダーID |
| `work-calendar-id@group.calendar.google.com` | 仕事用カレンダーのID |
| `0` が32個 / ゼロUUID | Notion のデータベースID・データソースID |
| `000000000` | GA4 のプロパティID |
| `/Users/you` | 自分のホームディレクトリ |
| 本業 / 業務委託先A / 顧問先B / 協業先C | 自分の勤務先・取引先 |
| You / 著者 / 担当者 / サンプル太郎 | 自分と関係者の名前 |

いくつかのスキルは外部サービスの MCP（Notion / Google Calendar / Gmail / GSC / GA4）を前提にしています。`kicho` は macOS の Excel、`video-edit` は `ffmpeg` が必要です。

## 動く状態にするまでの導入キット（有料・1,980円）

このリポジトリは置換済みで、CLAUDE.md や権限設定も含んでいないため、そのままでは動きません。
「おはよう」で朝のレポートが出るまでの導入手順・CLAUDE.md の雛形・settings.json の雛形・hooks 2本・置換漏れの確認スクリプトをまとめたものを BOOTH に置いています。

→ https://standbytech.booth.pm/items/8863683

## 自分の業務のどこから始めるか

ここに置いてあるのは、著者の業務に合わせて書かれたスキルです。同じものが自分の業務に刺さるとは限りません。
毎月どの作業に何時間使っているかを洗い出して、最初の一本の候補を出すところまでを無料の診断にしてあります（1〜2分）。

→ https://www.stand-bytech.com/ai-assessment?src=repo

## sanitize.py

同梱の `sanitize.py` は、**このリポジトリを作るのに使った置換スクリプトそのもの**です。自分のスキルを公開したいときに、そのまま流用できます。

```bash
python3 sanitize.py
```

- `RULES` に「説明・正規表現・置換後」を上から順に書く（順序に意味があります）
- 置換とは**独立に** `FORBIDDEN` で再検索し、漏れがあれば**終了コード1で止まる**
- 結果は `report.md` に出る

置換したことと、漏れがないことは別です。検証を分けているのはそのためです。詳しくは書籍の第10章に書きました。
