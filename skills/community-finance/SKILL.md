# コミュニティ 収支登録スキル

毎月のコミュニティ収支を、渡された明細（Stripeのスクショ、Google Cloud請求、FastSpringメール、ドメイン代など）から
仕分けして **Notion「コミュニティ 収支管理」DB** に登録する。

## 対象DB
- データベース: コミュニティ 収支管理
- URL: https://app.notion.com/p/00000000000000000000000000000000
- database_id: `00000000000000000000000000000000`
- data_source: `collection://00000000-0000-0000-0000-000000000000`
- 親ページ: 「コミュニティ」

## プロパティ（列）
| 列 | 型 | 備考 |
|---|---|---|
| 名前 | title | 取引名 or 支払者名 |
| 日付 | date | ISO `YYYY-MM-DD` |
| 種別 | select | `収入` / `支出` |
| カテゴリ | select | 会費 / 参加費 / 投げ銭 / 会場費 / 飲食費 / 備品・道具 / イベント / 交通費 / システム・ツール費 / その他 |
| 金額 | number(¥) | **円の整数**。外貨は概算換算して入れる |
| 支払方法 | select | 現金 / 銀行振込 / PayPay / クレジットカード / Stripe / その他 |
| メモ | rich_text | メール/補足・換算根拠など |
| 収支額 | formula | `if(prop("種別") == "収入", prop("金額"), prop("金額") * -1)`（符号付き。編集不要） |

## 仕分けルール（重要）
1. **Stripeの決済 = 収入**。カテゴリは `投げ銭`、支払方法は `Stripe`。
   - Stripe顧客一覧の「支出額合計」は顧客視点＝コミュニティの収入。1顧客=1行。
   - メモに顧客のメールアドレスを入れる。
2. **Stripe以外（Google Cloud / FastSpring / ドメイン / SaaS等） = 支出**。
   - カテゴリは基本 `システム・ツール費`、支払方法は `クレジットカード`。
   - Google Cloud は「利用料」と「消費税」を別行にする。
3. **精算・支払い行は除外（二重計上防止）**。
   - 例: Google Cloud請求書の「しきい値で請求 … −¥10,000（Amex決済）」は
     利用料の支払いなので入れない。利用料＋消費税だけを支出計上する。
   - ユーザーが「現金/カードの出入りも残したい」と明示した場合のみ追加。
4. **外貨（USD等）は円へ概算換算**。
   - レートが不明なら概算（例: ¥155/ドル）で換算し、メモに `$11 概算(≈¥155/ドル) ※円の実額があれば要修正` と明記。
   - カード明細の円実額が分かる場合はそちらを優先。
5. 日付が不明瞭なとき:
   - 請求期間は開始日（例: 6/1-6/30 → `2026-06-01`）。
   - FastSpring等の注文番号 `DATyymmdd-...` は日付として使える（`DAT260604` → 2026-06-04）。

## 手順
1. 渡された明細を読み取り、上のルールで各取引を JSON 配列に整形する。
   ```json
   [
     {"name":"サンプル太郎","date":"2026-06-14","kind":"収入","category":"投げ銭","amount":5000,"method":"Stripe","memo":"you@example.com"},
     {"name":"Google Cloud（6/1-6/30 利用分）","date":"2026-06-01","kind":"支出","category":"システム・ツール費","amount":9552,"method":"クレジットカード","memo":"Google Cloud 利用料"}
   ]
   ```
2. **登録前に、仕分け結果（収入計・支出計・収支差引と除外した行）を表にして必ずユーザーへ提示し、確認を取る**。
   - 特に「精算行の除外」「外貨換算レート」「カテゴリ判断」は明示する。
3. 承認後、JSONをテンポラリに保存して投入スクリプトを実行する:
   ```bash
   /Users/you/projects/standby/case-management-package/.venv/bin/python \
     /Users/you/.claude/skills/community-finance/insert_transactions.py \
     <transactions.json のパス>
   ```
   - トークンは case-management-package/.env の `NOTION_TOKEN` を使用（このDBへアクセス可能）。
   - 保護領域外への一時ファイルはセッションのscratchpadに置く。
4. 実行後、`収支差引` の合計をユーザーに報告する。

## 補足
- このNotionコネクタ(MCP)には**行追加ツールが無い**ため、書き込みは必ず上記の公式APIスクリプト経由で行う（列/ビュー変更のみ notion-update-data-source / notion-create-view が使える）。
- 収支差引の合計は、テーブル「取引一覧」の **収支額 列ヘッダーの計算メニュー → 合計** で表示される（設定済み）。
- 新カテゴリ/支払方法が必要になったら `notion-update-data-source` の `ALTER COLUMN "カテゴリ" SET SELECT(...)` で全選択肢を再指定して追加する（DBが空でなくても既存割当は保持される）。
