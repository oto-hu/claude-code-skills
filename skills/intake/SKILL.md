# intake — 受けるかどうかの門

Youが新しい仕事・案件・施策を引き受けるかを判定する。**4つの門を順番に通す。1つでも落ちたら受けない。**

この門は好き嫌いではなく、CliftonStrengths 34（2026-08-19受検）から導かれた**構造的な向き不向き**に基づく。
根拠：`~/.claude/projects/-Users-You/memory/user_strengthsfinder_profile.md`

判定は必ず**この順番**で行う。第1門で落ちたものを第2門以降で救済しない。

---

## 第1門：営業が要るか

> **「これは、誰かが売ってくれる形か？」**

- **YES（既存の信頼／紹介／エージェント／業務委託先Aの営業／コンテンツ経由の問い合わせ）** → 通過
- **NO（自分から新規に接触して取りに行く必要がある）** → **却下**

**根拠**：社交性33位・包含34位・コミュニケーション20位。新規開拓の営業は意志ではなく才能の底とぶつかる。過去、個別アウトリーチを3回設計し直して実行ゼロ。有償実績4件は全て知人経由。

**却下時の返し方**：「これは営業が要る形なので受けない」で終わらせず、**同じ目的を"売ってくれる形"に組み替えられないか**を1案だけ出す（例：自分でDM→業務委託先Aの営業に渡す／記事にして置いておく）。組み替えられないなら本当に却下。

---

## 第2門：残枠があるか

新規案件の受入枠は **月50〜70時間**。受託1件あたり **60〜80時間**。
→ **枠は常に1件分しかない。**

現在進行中のものを列挙し、残り時間を出す。固定消費の目安：

| 固定 | 時間/月 |
|---|---|
| オウンドメディアA記事（月4本・月7万） | 約20h |
| 業務委託先A稼働 | 約30h |
| 顧問先B 保守 | 約10h（※契約上は月2時間以内が上限） |
| 管理・発信 | 10〜30h |

- **残枠がある** → 通過
- **残枠がない** → **第3門へ進む前に「何を手放すか」を先に決める**。決まらないなら却下

**根拠**：達成欲3位「全体像が見える前に引き受け、期限に同意してしまう」／責任感8位「断るのが苦手で必要以上に引き受ける」。両方がレポートで名指しされている盲点。

---

## 第3門：保守・運用が付いてくるか

- **作って終わり** → 通過
- **保守・運用が付く** → **「月◯時間以内・対応範囲を列挙・範囲外は追加見積もり」を契約に書けるか**を確認する
  - 書ける → 通過
  - 書けない／相手が渋る → **却下**

金額ではなく時間で見る。月3万の保守は時給換算で2〜3時間分。それを超えた瞬間に赤字。

**根拠**：回復志向25位・規律性28位。「作るで燃えて、直す・維持するで消える」。範囲が書かれていない保守は、責任感8位が無限に対応してしまう。

## 第4門：可逆か不可逆か

| 種別 | 扱い |
|---|---|
| **可逆**（試す・出す・書く・デプロイする） | **即決してよい。24時間以内に決める。慎重さを使わない** |
| **不可逆**（退職・契約・大きな支出・撤回できない公開・人間関係を賭けるもの） | **慎重さ5位にフルで時間を渡す。数日かけてよい** |

**根拠**：未来志向1位（アクセル）と慎重さ5位（ブレーキ）が同時に最上位にある。使い場所を指定しないと、可逆な決定にまでブレーキがかかって止まる。

---

## 4門すべて通過したら

1. **1 in 1 out**：受けると同時に、手放すものを1つ名指しする。例外なし
2. **どこの枠でやるかを決める**：パワー時間①②（火・木20〜22時）に入れるのか、締切仕事として別に置くのか
   - パワー時間には**締切のない、独立に効くもの**しか入れない。納品・記事・保守は入れない
3. **数字を置く**：いくらか、何時間か、いつまでか。ここが空欄なら受けない
   （原点思考29位・運命思考30位＝「なぜやるか」では動かない。数値目標でしか動かない）

```
## 判定：受ける / 受けない

第1門 営業が要るか      ： 通過 / 却下 — 理由
第2門 残枠があるか      ： 通過 / 却下 — 残枠◯h、この案件◯h
第3門 保守が付くか      ： 通過 / 却下 — 範囲と上限を書けるか
第4門 可逆か不可逆か    ： 可逆（即決）/ 不可逆（◯日かけて判断）

【受ける場合】
手放すもの： ◯◯
やる枠　　： ◯◯
数字　　　： ◯円／◯時間／◯月◯日まで

【受けない場合】
却下した門と理由（1〜2文）
組み替え案（あれば1つだけ。なければ「なし」と書く）
```

## 使うときの注意

- **選択肢を3つ以上並べない。比較は1回だけ。24時間で決める。**
  着想21位・戦略性24位が低く、選択肢を並べると止まる。「もっと良い案がないか」と探し始めたら、それは検討ではなく回避。
- 代替案が要るときは自分で捻り出さず、`devil` / `ceo` エージェントに**「別の道を3つ出して、私の案を潰して」**と頼む。
- 判定結果が「受けない」でも、それを相手に伝えるときは**結論→理由**の順で話す（分析思考7位・慎重さ5位の検討プロセスを先に出すと「遅い」「疑っている」と誤解される）。
