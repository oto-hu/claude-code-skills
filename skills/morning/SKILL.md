# 朝のブリーフィングレポート

以下を**この順番で**自動実行して、まとめて1つのレポートとして出力する。
独立したステップ（メール取得・カレンダー取得・作業ログ読み込み）は並列で実行してよい。

## 前提情報

- **本業カレンダー（本業スケジュール）：** `work-calendar-id@group.calendar.google.com`
- **個人事業カレンダー（プライマリ）：** `you@example.com`
- **作業ログ：** `/Users/you/Documents/Obsidian Vault/Daily/`

## 1. 未読メールの取得（Gmail）

- 未読メールを最新20件取得する
- 件名・送信者・受信時刻を一覧表示する
- **プロモーション系（Amazon/楽天/LinkedIn/A8等のセール・通知・自動配信）は一覧から除外する**

## 2. 返信が必要なメールの抽出（Gmail）

以下の2軸でチェックする：
- **未読**で、質問・依頼・確認を求める内容が自分宛て（CCではない）に送られているもの
- **既読**でも、スレッドの最後が相手の発信で終わっていて自分が返信していないもの

既に返信済みのスレッドは除外する。

## 3. 今日のスケジュール取得（Google Calendar）

本業・個人事業を分けて表示する。
- イベントにZoom・Google MeetなどのURLがある場合（description または location に含まれる）、**必ずリンクを「場所・リンク」列に表示する**。省略しない。

## 4. 作業ログからレコメンドTODO生成

- `/Users/you/Documents/Obsidian Vault/Daily/` 配下の直近7日分のMDファイルを読み込む
- 各ファイルの「## 日次要約」と「## 翌日のTODO」セクションを抽出する
- ファイルが存在しない・読めない日はスキップする
- 以下の観点でレコメンドTODOを5件以内で生成する：
  - 複数日にまたがって未完了のまま繰り返し登場しているタスク（放置気味のもの）
  - 昨日の要約に含まれる「次やること」「継続中」の文脈
  - 本業・個人事業のバランスを考慮し、偏りがあれば補正する
  - 今日のスケジュールと照らし合わせ、空き時間に合う粒度で提案する
- **ポイント期限・セール・販促系はTODOに昇格させない**（メール一覧への掲載は可）
- 各TODOには【本業】【個人】のラベルを付ける
- 各TODOには以下を必ず含める：
  - **具体的なアクション**：「〜する」で終わる動詞ベースの行動（何を・どこで・どう操作するか）
  - **完了条件**：何ができたら「終わり」と言えるか（成果物・状態・送信済みなど）
  - **目安時間**：15分/30分/1時間 など大まかな見積もり
